## If something goes sideways — add

- **No 📊 guidance line in the cart** → the basket's margin band needs 3+
  decided quotes; the seeded history covers 15–30%+ bands on a fresh browser.
- **No health dot** → select a customer in "Quoting for" first.
- **Metals strip missing** → it shows on the landing view only (clear search
  and filters); the copper nudge only appears when copper trends up that day.
- **Job Wizard step says "No match"** → that subcategory search found nothing;
  swap an alternate on another step or search manually — every default
  template query is verified against the catalog.
